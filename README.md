# CSXCAD (alpLab fork)

A C++ library to describe geometrical objects and their physical or non-physical properties. This is the [alpLab](https://github.com/alplabai) fork, maintained for integration with [openEMS](https://github.com/alplabai/openEMS) and [Signex](https://github.com/alplabai/alp-eda).

**Upstream**: [https://github.com/thliebig/CSXCAD](https://github.com/thliebig/CSXCAD)

## Changes from upstream

- Fix iterator UB after erase in primitive processing
- Fix `UpdateIDs` logic bug
